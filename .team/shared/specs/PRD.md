## 1. 产品概述

### 1.1 产品基本信息

| 项目 | 内容 |
|------|------|
| 产品名称 | 命运占卜 |
| 产品定位 | 一款融合中西方命理智慧的微信小程序，为用户提供专业、便捷的算命与占卜服务 |

## 2. 现状分析

### 2.1 当前版本功能清单

当前项目是一个**微信小程序原型/Demo阶段**，具备以下功能：

| 模块 | 功能 | 状态 | 说明 |
|------|------|------|------|
| 首页 | 品牌展示 + 入口导航 | ✅ 已实现 | Hero区域 + 两个CTA按钮 |
| 中式算命 | 八字算命 | ⚠️ Demo | 有表单输入，但结果为硬编码Mock数据 |
| 中式算命 | 周易六爻 | ⚠️ Demo | 有表单输入，但结果为硬编码Mock数据 |
| 西式算命 | 塔罗占卜 | ⚠️ Demo | 有表单输入，但结果为硬编码Mock数据 |
| 西式算命 | 星盘解析 | ⚠️ Demo | 有表单输入，但结果为硬编码Mock数据 |
| 关于页 | 产品介绍 | ✅ 静态内容 | 固定文本，无动态内容 |
| TabBar | 四Tab导航 | ✅ 已配置 | 首页 / 中式 / 西式 / 关于 |

### 2.2 存在的核心问题

#### 问题 1：所有测算结果均为假数据（严重程度：🔴 致命）

当前 `chinese.js` 和 `western.js` 的提交函数中，所有结果都是写死的 Mock 数据。无论用户输入什么，返回的都是相同的固定文本。这意味着**产品目前完全不可用**——没有任何真实的命理计算逻辑。

**影响**：用户使用一次即流失，无法建立信任感。

#### 问题 2：缺少后端服务支撑（严重程度：🔴 致命）

所有逻辑都在前端 JS 中完成，没有服务端接口。这导致：
- 无法接入真实的八字排盘算法
- 无法存储用户的测算历史
- 无法实现任何付费功能
- 数据安全性无法保障

**影响**：无法上线运营。

#### 问题 3：无用户系统（严重程度：🟠 严重）

- 没有登录/注册机制
- 没有 `wx.login` 接入
- 无法识别用户身份
- 测算结果无法保存和回顾

**影响**：无法建立用户体系，无法做用户运营和留存。

#### 问题 4：首页价值感不足（严重程度：🟠 严重）

当前首页只有一个简单的 Slogan 和两个按钮：
- 缺乏每日运势等吸引用户回访的内容
- 缺乏社会证明（使用人数、好评等）
- 缺乏新用户引导
- 与中式/西式 Tab 功能重复（首页的两个按钮和 TabBar 入口重叠）

**影响**：新用户打开后的第一印象平淡，缺乏"wow moment"。

#### 问题 5：缺少结果分享能力（严重程度：🟠 严重）

- 测算完成后无法生成分享图片
- 无法分享到朋友圈或好友
- 对于命理类产品来说，社交传播是核心增长手段之一

**影响**：丧失了最自然的获客渠道。

#### 问题 6：关于页过于简陋（严重程度：🟡 一般）

只有四行静态文字，缺少：
- 版本信息
- 用户协议/隐私政策链接
- 免责声明（命理类产品的法律必备项）
- 反馈入口

**影响**：合规风险 + 专业感缺失。

#### 问题 7：无加载态和异常处理（严重程度：🟡 一般）

- 没有 loading 动画
- 表单验证不完善
- 无网络异常提示
- 无"测算中"的过渡体验（命理产品的重要仪式感来源）

**影响**：用户体验粗糙，不够精致。

## 3. 竞品分析

### 3.1 测测 App

**定位**：国内领先的手机算命App，涵盖星座、塔罗、八字、生肖等多维度命理服务

| 维度 | 分析 |
|------|------|
| **核心功能** | 星座日运/周运/年运、塔罗牌占卜、八字合婚、姓名测试、风水罗盘、择吉日历 |
| **体验亮点** | ① 每日推送日运通知，形成强日活习惯 ② AI解盘功能，结合大模型生成个性化解读 ③ 社区氛围好，用户可发帖互动 ④ 会员体系成熟（测测VIP） |
| **商业模式** | Freemium：基础日运免费，深度解读/AI对话/专属报告需VIP |
| **估值参考** | 累计下载量超亿级，融资多轮 |
| **可借鉴点** | 每日运势推送是命理App的核心抓手；AI解盘是差异化趋势 |
| **不足/机会** | 功能过于庞杂，新用户上手成本高；我们可以走"精而美"路线 |

### 3.2 易奇八字

**定位**：专注于中国传统命理学的专业型App

| 维度 | 分析 |
|------|------|
| **核心功能** | 八字排盘、大运流年、六爻预测、紫微斗数、梅花易数、奇门遁甲 |
| **体验亮点** | ① 专业度极高，排盘数据完整准确（含神煞、纳音等） ② 支持多种排盘模式（三柱/四柱/五柱） ③ 有专业的命理文章库和视频课程 ④ 合婚功能做得深入 |
| **商业模式** | 基础排盘免费，高级分析（如终身运程详批）收费29.9-99元不等；在线大师咨询按分钟计费 |
| **市场表现** | 在专业用户群体中有较高口碑 |
| **可借鉴点** | 专业性建立壁垒；在线大师咨询是高毛利业务 |
| **不足/机会** | UI偏老旧，对新用户不够友好；西式占卜覆盖弱；我们可以在"专业+现代感"之间找平衡 |

### 3.3 新浪星座 / 手机星座网

**定位**：面向年轻群体的星座娱乐平台

| 维度 | 分析 |
|------|------|
| **核心功能** | 12星座日运/周运/月运/年运、星座配对、星座性格分析、星座排行榜、月亮星座查询 |
| **体验亮点** | ① 内容更新频率高，每天都有新鲜内容 ② 配对功能极具社交传播力（"你和TA的匹配度98%！"） ③ 与微博/新浪生态打通，流量优势明显 ④ UI风格活泼，符合年轻人审美 |
| **商业模式** | 广告收入为主 + 部分付费深度报告 |
| **市场表现** | 流量大，但用户黏性相对一般 |
| **可借鉴点** | 配对功能天然适合社交裂变；内容运营驱动日活 |
| **不足/机会** | 过于偏向娱乐化，专业用户不买账；中式命理几乎空白；我们可以在"专业+有趣"之间差异化 |

### 3.4 塔罗牌类独立App（如：Galaxy Tarot、Mystic Mondays）

**定位**：以塔罗为核心的视觉导向型App

| 维度 | 分析 |
|------|------|
| **核心功能** | 多种牌阵选择、每日一牌、塔罗学习库、自定义牌组、日记记录 |
| **体验亮点** | ① 牌面视觉极其精美（这是塔罗App的生命线） ② 抽牌过程有强烈的仪式感动画 ③ 学习模块帮助新手理解每张牌的含义 ④ 日记功能增加用户粘性 |
| **商业模式** | 免费版限制牌阵数量，解锁全部牌阵/牌组需一次性购买或订阅（$4.99-$19.99） |
| **市场表现** | 在海外市场表现良好，国内用户群体较小众 |
| **可借鉴点** | 视觉设计和仪式感动画是塔罗功能的成败关键；日记/记录功能提升留存 |
| **不足/机会** | 国内用户对纯塔罗的需求规模有限；我们需要将塔罗作为组合拳中的一环 |

## 4. 功能规划

### 4.1 P0 — MVP必做（第一版上线前提）

#### F001：真实八字排盘引擎

| 项目 | 内容 |
|------|------|
| **功能名** | 八字排盘测算 |
| **描述** | 根据用户输入的出生年月日时和性别，进行真实的八字排盘计算，输出天干地支、五行分布、十神关系、日主强弱等基础数据，并附带通俗的命运分析文案 |
| **用户故事** | As a 迷茫职场人, I want 输入我的出生信息后看到准确的八字排盘和分析, So that 我能了解自己的性格特点和人生趋势，为决策提供参考 |
| **技术要点** | 需要实现或接入八字排盘算法（转换公历→农历、计算干支、推算十神、判断日主强弱）。建议优先使用成熟的JS算法库（如 `lunar-javascript`）在前端完成，后续迁移至后端 |
| **验收标准** | ✅ 输入任意合法日期，能正确输出八字（年柱/月柱/日柱/时柱） <br>✅ 能正确显示五行统计（金木水火土各几个） <br>✅ 能正确显示十神格局 <br>✅ 日主强弱判断基本合理 <br>✅ 附带至少200字的性格/事业/财运分析文案 <br>✅ 农历转换准确（对照万年历验证） |

#### F002：真实塔罗抽牌引擎

| 项目 | 内容 |
|------|------|
| **功能名** | 塔罗占卜 |
| **描述** | 用户选择牌阵和问题后，从78张塔罗牌中随机抽取对应数量的牌，展示正/逆位，并给出针对问题和牌面的解读文案。需要有抽牌仪式感动画 |
| **用户故事** | As a Z世代探索者, I want 选一个问题然后像真的洗牌抽牌一样看到我的塔罗结果, So that 我能得到有趣的指引并且可以截图分享给朋友 |
| **技术要点** | 78张大阿尔卡纳+小阿尔卡纳的牌义数据库；随机抽取算法；正逆位概率控制（通常50/50）；牌阵位置含义映射；需要准备每张牌的图片资源 |
| **验收标准** | ✅ 包含22张大阿尔卡纳 + 56张小阿尔卡纳 <br>✅ 支持3种以上牌阵（三牌阵/凯尔特十字/时间之流） <br>✅ 每张牌有正位和逆位两种解读 <br>✅ 解读文案结合了用户的问题上下文 <br>✅ 抽牌过程有翻牌动画（至少1秒的仪式感） <br>✅ 牌面清晰美观，支持保存为图片 |

#### F003：真实星盘计算

| 项目 | 内容 |
|------|------|
| **功能名** | 星盘解析 |
| **描述** | 根据出生日期、时间、地点，计算太阳星座、月亮星座、上升星座、金星星座、火星星座等核心行星落座，以及主要的相位关系，输出人格分析 |
| **用户故事** | As a 对星座感兴趣的年轻人, I want 输入我的出生信息后看到我的星盘全貌, So that 我能深入了解自己的星座构成，不止停留在太阳星座层面 |
| **技术要点** | 需要天文计算算法（瑞士星历表 ephemeris 数据或近似公式）；经纬度 → 时区转换；恒星时计算；行星位置推算。推荐使用 `astronomy` 或 `swiss Ephemeris` 相关库 |
| **验收标准** | ✅ 正确计算太阳/月亮/上升星座（与主流App交叉验证） <br>✅ 至少显示内行星（水金火木土）+南北交点 <br>✅ 显示主要相位（冲/刑/六合/三合） <br>✅ 输出300字以上的性格分析 <br>✅ 支持国内外城市地点选择（至少覆盖省会城市） |

#### F004：周易六爻测算

| 项目 | 内容 |
|------|------|
| **功能名** | 周易六爻预测 |
| **描述** | 用户输入问题和起卦时间/手动摇卦后，根据铜钱摇卦法生成六爻卦象，包含世应/六亲/六兽/动变爻，给出断卦解读 |
| **用户故事** | As a 相信传统命理的用户, I want 针对我的具体问题进行六爻占卜, So that 我能在做重要决定前得到来自易经的指引 |
| **技术要点** | 铜钱摇卦模拟（3枚硬币×6次）；64卦+384爻的卦辞爻辞数据库；世应六亲推导；动爻变卦逻辑；需要完整的易经文本库 |
| **验收标准** | ✅ 正确生成6爻卦象（本卦+变卦） <br>✅ 正确标注世爻、应爻 <br>✅ 正确标注六亲（父母/兄弟/子孙/妻财/官鬼） <br>✅ 正确标注六兽（青龙/朱雀/勾陈/螣蛇/白虎/玄武） <br>✅ 动爻和变卦逻辑正确 <br>✅ 断卦解读不少于200字 |

#### F005：用户系统（微信授权登录）

| 项目 | 内容 |

### 8.2 会员体系设想（V2阶段）

| 等级 | 价格 | 权益 |
|------|------|------|
| **免费用户** | ¥0 | 每天3次免费测算（基础结果）/ 每日基础运势 / 分享功能 |
| **月卡会员** | ¥18.8/月 | 无限次测算 + 完整解读 + AI对话（每天10次）+ 报告导出 + 去广告 |
| **年卡会员** | ¥128/年 | 同月卡 + 年度大运详批 + 专属客服 + 新功能优先体验 |
| **单次付费** | 按次结算 | 灵活购买某一次的完整解读（适合低频用户） |

**定价逻辑**：
- 月卡 ≈ 2杯奶茶钱，决策门槛低
- 年卡约为月价的5.7折，鼓励长期付费
- 单次价格在 5-15 元区间，符合小额高频的微信生态消费习惯

### 8.3 变现路径规划

#### 阶段一：种子期（MVP → 上线后3个月）
- **目标**：验证产品价值，积累初始用户
- **变现**：基本不变现，专注用户体验和口碑
- **重点**：免费提供所有基础功能，通过分享机制获取用户

#### 阶段二：探索期（上线后3-6个月）
- **目标**：验证付费意愿
- **变现**：
  - 推出"完整解读"付费解锁（¥9.9/次）
  - 尝试单次付费模式
  - A/B测试不同价格点
- **重点**：关注付费转化率和复购率

#### 阶段三：增长期（上线后6-12个月）
- **目标**：建立稳定的收入模型
- **变现**：
  - 推出会员体系（月卡/年卡）
  - AI解读功能上线（高毛利）
  - 在线大师咨询（佣金模式）
  - 可能引入原生广告（腾讯广告联盟）
- **重点**：ARPU（每用户平均收入）和 LTV（生命周期价值）

#### 阶段四：成熟期（上线12个月+）
- **目标**：多元收入，规模化盈利
- **变现**：
  - 成熟会员体系
  - B端合作（企业团建活动中的命理娱乐服务）
  - IP联名/周边
  - 命理课程/知识付费
- **重点**：利润率 + 品牌影响力

### 8.4 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 微信平台政策收紧（命理类属敏感领域） | 🔴 可能被下架 | ① 所有结果加免责声明 ② 定位强调"文化传承""娱乐参考" ③ 避免夸大宣传词汇（"百分之百准""改变命运"等） |
| 用户付费意愿低于预期 | 🟠 收入不达预期 | ① 先跑通免费模式做大用户基数 ② 降低首次付费门槛（如首月¥1体验） ③ 优化付费节点设计 |
| 竞品抄袭/巨头入场 | 🟡 市场竞争加剧 | ① 在"中西融合"和"设计品质"上建立差异化 ② 快速迭代保持领先 ③ 构建内容/社区壁垒 |
| 命理准确性争议 | 🟠 口碑受损 | ① 使用经过验证的算法库 ② 明确设定预期（"仅供参考"） ③ 持续收集反馈优化文案质量 |
